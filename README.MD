# 67 CAD v1.0-beta

**67 CAD** — это браузерный редактор принципиальных схем, созданный для проектирования электронных устройств на базе Arduino. Он не требует установки, работает на чистом HTML/CSS/JS и позволяет рисовать схемы, сохранять их в JSON и экспортировать в PNG.

## 🚀 Возможности

*   **Библиотека компонентов**: Arduino Uno R3, 4-разрядный индикатор 3461BS, резисторы, конденсаторы, транзисторы (PNP/NPN), кнопки, светодиоды, динамики, шины питания и узлы.
*   **Три режима работы**:
    *   **Редактор** — перемещение компонентов, изменение их номиналов и подписей.
    *   **Трассировка** — прокладка проводов между контактами с возможностью создания точек излома.
    *   **Удаление** — быстрое удаление проводов и компонентов кликом мыши.
*   **Умные провода**: привязка к контактам, изменение цвета из палитры, автоматическая подсветка.
*   **Шины и узлы**: VCC и GND площадки для организации питания, а также узлы для соединения проводов.
*   **Записки**: текстовые блоки с возможностью изменения размера и шрифта.
*   **Горячие клавиши**: `Ctrl+Z` (отмена), `Ctrl+C` / `Ctrl+V` (копирование/вставка), `Delete` (удаление).
*   **Сохранение**: экспорт схемы в JSON для повторной загрузки и сохранение в PNG высокого разрешения.
*   **Темы**: темная и светлая темы интерфейса и холста.

## 📦 Установка и запуск

1. Скачайте все файлы проекта в одну папку:
   *   `index.html`
   *   `style.css`
   *   `script.js`
   *   `components.js`
2. Откройте файл `index.html` в любом современном браузере (Chrome, Firefox, Edge, Safari).
3. Готово! Сайт работает локально, без необходимости в сервере или интернете.

## 📖 Как пользоваться

### Режимы работы
*   **Редактор**: кликните по компоненту, чтобы выделить его. Перетаскивайте мышью, чтобы переместить. Двойной клик по резистору, конденсатору или кнопке открывает поле для изменения значения/подписи.
*   **Трассировка**: кликните по контакту (пину), чтобы начать провод. Кликайте по пустому месту, чтобы создать точки излома. Завершите провод, кликнув по второму контакту.
*   **Удаление**: кликните по проводу или компоненту, чтобы удалить его.

### Камера
*   **Колесико мыши** — зум.
*   **Зажатая правая кнопка мыши (ПКМ)** — панорамирование холста.

### Горячие клавиши
*   `Ctrl+Z` — отменить последнее действие.
*   `Ctrl+C` — скопировать выделенные компоненты.
*   `Ctrl+V` — вставить скопированные компоненты со смещением.
*   `Delete` / `Backspace` — удалить выделенные компоненты.

### Создание компонентов
Используйте левую панель для добавления компонентов на холст. Они появятся в центре видимой области.
